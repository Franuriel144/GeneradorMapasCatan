# Torneo Catán — generador de mapas

Abre `index.html` en un navegador. La aplicación funciona sin conexión y no necesita instalación.

- Genera la distribución estándar de 19 terrenos.
- Mantiene los números ocultos mediante las letras A–R del reverso de las fichas.
- Permite revelar los números después de colocar los poblados.
- Evita 6/8 adyacentes y controla el reparto de probabilidades por recurso.
- La semilla permite volver a generar exactamente el mismo mapa.
- Incluye vista de impresión A4 horizontal.

Herramienta no oficial para organización de torneos.
